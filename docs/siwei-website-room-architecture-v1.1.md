## 壹、核心修正與設計原則

本 V1.1 版本依據審閱意見，落實以下關鍵原則調整：

### 1. 租金呈現原則（避免「同一房間有不同租金」之誤解）
* **問題防範：** 若房型頁僅標示「6,200 ~ 6,800 元/月」，租客容易誤以為「同一間房間可依條件選擇不同價格」。
* **呈現標準：** 
  - 房型卡片標註格局租金範圍時，**必須於同一視角內清楚列出各實際房間的專屬租金與出租現況**。
  - 範例格式：
    > **SG-01 格局（301 / 501）**
    > - 301 房：6,800 元／月 ｜ 【目前已出租】
    > - 501 房：6,200 元／月 ｜ 【目前已出租】
  - 明確傳達：租金是**固定綁定各實際房號**，而非同一房間之浮動價格。

### 2. Type 05（308 / 508）公開標示修正
* **內部確認事實：**
  - 308 房：月租 4,200 元，目前出租，為**屋主親戚特殊承租、空屋出租、沒有附任何設備**。
  - 508 房：月租 5,000 元，目前出租（依租約紀錄表）。
* **公開呈現原則：**
  - **不得將 5,000 元定義為 Type 05 的公開起租價**（因為目前該房型並無空房可供招租）。
  - 對外網站 Type 05 標示：**【目前無空房】**（或滿租中）。
  - 對外網站**不必公開 308 的特殊 4,200 元租金**，避免未來招租時引起比價爭議。
  - 內部 Master Data 則完整保留 308 之 4,200 元、特殊承租、無設備等完整事實。

### 3. 房型名稱中性化（杜絕未經證實之形容詞）
* **原則：** 除非現有人工資料明確支持，否則**一律不使用「景觀」、「優選」、「經典」等未經佐證的行銷詞彙**，全數採用客觀、中性的房號與格局名稱。
* **名稱修訂：**
  - Type 06：原「景觀獨立套房」→ 修正為 **「503 獨立套房」**
  - Type 09：原「六樓景觀套房」→ 修正為 **「603 獨立套房」**
  - Type 10：原「六樓優選套房」→ 修正為 **「605 獨立套房」**
  - Type 11：原「六樓優選套房」→ 修正為 **「606 獨立套房」**
  - Type 01～05：統一修正為 **「301 / 501 套房（同格局）」** 等中性命名。

### 4. 照片使用規範（標準化圖說標註）
* 307 房目前為空房，但自身無直接照片；經人工確認，307 與 507 為相同格局。
* 307 招租卡片與頁面可使用 507 的實景照片作為同格局參考，但**相片下方必須固定並明確標示標準文字**：
  > **「507房實景｜307同格局參考，實際現況以現場帶看為準」**
* 嚴禁將 507 照片標註為 307 現況照。

### 5. 首頁「目前可租」精準聚焦
* 物件首頁最核心的「目前可租房源」區塊，**嚴格只列出目前真正釋出的 3 間空房**：
  1. **307 房：** 6,500 元／月 ｜ 3F 套房 ｜ 附 507 同格局參考照
  2. **605 房：** 6,800 元／月 ｜ 6F 獨立套房 ｜ 附 7 張實景相簿
  3. **606 房：** 6,800 元／月 ｜ 6F 獨立套房 ｜ 附 6 張實景相簿
* 這 3 間房作為首頁最主要的招租行動呼籲（CTA）。

### 6. 非出租房號（303、306、506）
* **維持完全不對外公開。**
* 公開網站前端（選單、房型卡、房間清單、可租列表）完全不露出，僅留存於內部 Master Data。

## 參、三層結構具體配置方案

### 第一層：物件首頁 (`properties/siwei/index.html`)

1. **頂部導覽（Nav）：**
   - 四維三路59號 ｜ 房源特色 ｜ 費用與公設 ｜ 房型總覽 ｜ **【目前可租房源】** ｜ 預約看屋
2. **Hero 視覺區：**
   - 標題：高雄市苓雅區四維三路59號・優質分租套房
   - 特色標籤：近四維行政中心・生活機能完備・專人垃圾處理・獨立電表
3. **🔥【主要招租核心】目前可租房源（Availability Section）：**
   - 只展示目前 3 間空房，三卡並排：
     * **卡片 1（605 房）：** 6,800 元／月 ｜ 6F 獨立套房 ｜ 實景相簿（7張） ｜ 【立即預約看屋】
     * **卡片 2（606 房）：** 6,800 元／月 ｜ 6F 獨立套房 ｜ 實景相簿（6張） ｜ 【立即預約看屋】
     * **卡片 3（307 房）：** 6,500 元／月 ｜ 3F 套房 ｜ 同格局參考照（拍攝自507） ｜ 【超值釋出・預約帶看】
   - 點擊預約直接引導至 LINE，自動帶入想預約之房號。
4. **全棟費用透明公開區：**
   - 租金包含：水費、網路、第四台、垃圾集中處理。
   - 電費：依台電帳單按各房獨立電表公平分攤。
   - 押金：2 個月。
   - **無電梯（公寓樓梯動線）**、無天然瓦斯、無私人陽台、無車位。
5. **公共設施與生活機能：**
   - 洗衣設備（公共洗衣機）、公共曬衣區。
   - 周邊機能：復興二路、四維三路商圈、超商、餐飲。
6. **12 房型入口導覽（Room Types Grid）：**
   - 展示 Type 01 ～ Type 12 之卡片。
   - Type 04（含307）、Type 10（605）、Type 11（606）顯示亮色「有空房」標籤。
   - 其餘 9 個房型顯示「目前無空房」。

### 第二層：房型詳細頁 (`properties/siwei/types/{01~12}/index.html`)

共 12 個獨立房型頁面，每頁結構如下：

1. **房型標題與狀態 Header：**
   - 客觀房型名稱（例如：`307 / 507 套房（同格局）`）。
   - 狀態 Badge（【有空房釋出】或【目前無空房】）。
2. **相簿展示區（Carousel）：**
   - 展示該房型之實景或同格局參考相簿。
   - 強制掛載客觀圖說標註（例如 307/507 頁標註：`507房實景｜307同格局參考，實際現況以現場帶看為準`）。
   - 601、602、607 無照片房型展示規格卡（不放假照片）。
3. **房間現況與個別租金清單（Room Status Table）：**
   - 清晰列出該房型涵蓋之各個房號，逐一呈現租金與狀態（例如：`307 房：6,500 元／月 ｜ 目前空房`、`507 房：8,610 元／月 ｜ 目前已出租`）。
   - 杜絕租金浮動之誤解。
4. **房間設備清單：**
   - 共通配備：桌椅、床、衣櫃、冷氣、電視、冰箱、第四台、寬頻網路。
   - 衛浴設施：浴缸或淋浴空間（依各房型照片可見特徵客觀描述）。
5. **費用與看屋說明：**
   - 水電分攤方式、押金規範。
6. **預約與諮詢 CTA：**
   - 官方 LINE 按鈕（預填該房型與房號文字）。

### 第三層：房間層（內嵌於房型頁內）

* 延續分租套房的最佳實務，不為 17 間房建立 17 個單薄網頁，而是將「房間層」直接作為「房型詳細頁」內的「核心實體列表」。
* 租客在房型頁中既能理解空間格局，又能立刻查閱該房號的專屬租金與當前是否已被承租。
